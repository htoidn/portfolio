# Portfolio — Full-Stack Developer

A dark, animated static portfolio built with vanilla HTML, CSS, and JavaScript.

## Features

- Particle canvas with mouse interaction
- Custom cursor with follower effect
- Scroll reveal animations
- Animated skill bars & counters
- Responsive & mobile-friendly

## Structure

```
portfolio/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Deploy to GitHub Pages

1. Create a repo named `github.com/htoidn/portfolio`
2. Upload all files to the `main` branch
3. Go to **Settings → Pages → Branch: main → Save**
4. Live at `https://htoidn.github.io/portfolio/`

## Customize

| What | Where |
|------|-------|
| Your email | `index.html` → `mailto:adminecoroute@gmail.com` |
| GitHub links | `index.html` → project card `href` |
| Resume file | Upload `resume.pdf`, update the Download button `href` |
| Name / title | `index.html` → hero section |
